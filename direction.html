My Direction in ICT

There are a lot of different jobs in ICT. I'm still exploring them, but two areas that interest me are software engineering and data science.

Software Engineering

Software engineers build and maintain programs, websites and apps. I like the idea of creating something useful from code.

Data Science

Data science is about using data to find patterns and answer questions. It also uses programming, which is something I want to improve at.

Which one would I choose?

At the moment, software engineering sounds more interesting to me because I want to build websites and applications. But I want to learn more about both before deciding.

What I'll do next

Keep practising HTML, CSS and JavaScript, finish my assignments and try some small projects.
